# Cara instal skill "video-reverse-engineer" di Claude

Skill ini harus dipasang sendiri oleh tiap anggota tim di akun Claude mereka.

## Untuk tiap anggota tim (paket Pro / Max / Team / Enterprise)
1. Unduh file **video-reverse-engineer.zip** (jangan di-unzip).
2. Buka claude.ai, klik nama/foto profil di kiri bawah, pilih **Settings**.
3. Buka menu **Capabilities**. Pastikan **Code execution and file creation** aktif (skill butuh ini).
4. Di bagian **Skills**, klik **Upload skill**, pilih file zip tadi.
5. Pastikan skill **video-reverse-engineer** dalam posisi aktif (toggle on).

## Cara pakai
Di chat baru, upload video referensi (atau screenshot per adegan) plus foto produk sesuai urutan yang nanti di-upload ke TikTok Symphony, lalu tulis misalnya:

> Reverse engineer video ini jadi prompt TikTok Symphony untuk produk di foto. Voice over, tanpa wording.

Claude akan otomatis memakai skill ini dan memberi file prompt per adegan.

## Untuk admin paket Team / Enterprise
Admin organisasi bisa membagikan skill ke seluruh anggota sekaligus dari **Admin settings** (bagian Skills / Capabilities), sehingga anggota tidak perlu upload satu per satu. Nama menu bisa sedikit berbeda tergantung versi claude.ai.

## Catatan
- Paket gratis (Free) belum bisa memakai skill custom.
- Kalau skill diperbarui, hapus versi lama di Settings lalu upload zip yang baru.
- Contoh di dalam skill memakai brand TULANDUT hanya sebagai contoh gaya.
